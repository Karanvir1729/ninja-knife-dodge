# Ninja Knife Dodge

Two games in one offline arcade, built with [Godot 4](https://godotengine.org) for iPhone and iPad.

- **Knife Dodge** (reflex) — you are a lone star adrift in the void. Tap to propel yourself away from your finger and dodge escalating waves of daggers: volleys, crossfire, closing rings and rows that snap shut like teeth. Near misses build a streak for bonus points. One hit ends the run.
- **Shuriken Match** (puzzle) — a match-3 with 50 formula-driven levels. Line up three shurikens to clear them, hit the target score before the moves run out, and earn up to three stars per level. Four in a row forges a **Line** shuriken, an L or T forges a **Burst**, five in a row forges a **Prism**, and swapping two specials together makes crossfires, mega bursts and total eclipses.

Both games share one menu, one tutorial format (instruction on top, a glowing helper to tap, step dots), a pause overlay, local top-10 leaderboards with lifetime stats and milestone titles, and a settings screen (ninja name, music, sound, haptics, tutorial replay, reset).

- One-touch controls, landscape, fully offline
- Local leaderboards only — no ads, no accounts, no network, no data collection
- Fills iPhone (19.5:9) and iPad (4:3) screens edge to edge, with safe-area aware HUDs
- Ships on the iOS App Store as **Ninja Knife Dodge**

## Project layout

- `States/` — every screen is a state scene swapped by `state_machine.gd` with a fade: `start` (menu), `tutorial`/`play`/`lose` (Knife Dodge), `match_levels`/`match_tutorial`/`match_play`/`match_result` (Shuriken Match), `leaderboard`, `settings`
- `match/` — `board_model.gd` (pure match-3 rules: runs, specials, combos, gravity, refill, shuffle, full move resolution), `board_view.gd` (rendering, input, animation), `tile.gd`, `levels.gd` (level formulas), `tutorial_layouts.gd`
- `player/`, `objects/` — the star, the daggers and the wave spawner
- `autoload/` — `SaveData` (JSON save at `user://save.json`, migrates the v1 high score), `AudioManager` (music crossfade, pooled SFX, haptics), `DebugTour` (screenshot + smoke test harness)
- `UI/` — `theme.tres` (neon theme: button variants, labels, panels, sliders), starfield background, transition, pause overlay, HUD, toggle
- `graphics/gen/`, `sounds/gen/` — sprites and sound effects generated by `tools/gen_assets.py` (Pillow) and `tools/gen_sfx.py` (stdlib only); re-run them to regenerate
- `fonts/` — Game Continue 02 (titles) and Chakra Petch (UI, SIL OFL)
- `ios_icons/` — App Store icon set (iPhone and iPad sizes)
- `docs/` — support page and privacy policy (GitHub Pages)
- `tests/` — headless tests for the match-3 model and the level-curve tuning bot

## Design tokens

Background `#07080d`, panels `#0e0f16`, borders `#262a3d`, text `#ebeef8`, muted `#8b92ab`. Cyan `#56f0ff` is Knife Dodge, magenta `#ff4fd8` is Shuriken Match, gold `#ffd84d` is stars and records. All screens were designed at the 1408×792 base viewport so design coordinates map 1:1 onto scene coordinates.

## Running and testing

Godot 4.3 or newer (developed and verified with 4.7.2).

```bash
godot --path .                                   # play
godot --headless --path . -s tests/test_board.gd # match-3 rules + level curve bot
godot --headless --path . -- --check             # load every script and scene
godot --path . -- --tour=/tmp/ninja-shots        # screenshot every screen at 16:9, iPhone and iPad ratios, then run gameplay smoke checks
```

The tour uses in-memory sample data only; nothing is written to your save file.

## Building for iOS

Open in Godot, export with the **iOS** preset (generates an Xcode project; `export_project_only=true`), then archive and upload with Xcode. The preset's `application/version` is the build number — bump it before every upload. The preset targets iPhone and iPad (`targeted_device_family=2`) in landscape only.
